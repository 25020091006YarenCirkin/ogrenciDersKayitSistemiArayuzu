#  Student Course Management System

A desktop course registration interface developed using **Java Swing**. This project demonstrates the design of a graphical user interface (GUI) for managing student course selections.

The interface displays student information, available courses, course credits, and provides buttons for adding or removing courses. It was developed as a practice project for learning Java Swing and desktop application development.

---

##  Features

- Student information panel
- Course list display
- Course credit information
- Add/Remove course buttons
- Course selection interface
- User-friendly desktop GUI
- Developed with Java Swing

---

##  Technologies

- Java
- Java Swing
- GUI Development

---

##  How to Run

2. Open the project using NetBeans, IntelliJ IDEA, or Eclipse.
